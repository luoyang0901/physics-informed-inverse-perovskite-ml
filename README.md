# Interpretable Machine Learning for Inverse Perovskite Solar Cells

This repository provides the dataset and Python code associated with the manuscript:

**Interpretable Machine Learning with Physically Informed Feature Engineering for Modeling the Simulated Performance of Inverse (Anti-)Perovskite Solar Cells**

The repository is designed for reproducibility. Only the source dataset and analysis script are provided. All result tables used for manuscript preparation can be regenerated by running the code.

## Repository contents

```text
.
├── A3BX3.py        # Main Python script for data cleaning, feature construction, model training, validation, and table generation
├── dataset.csv     # Curated dataset used in this study
├── README.md       # Repository description and usage instructions
└── requirements.txt  # Python package dependencies, recommended
```

The output files are not uploaded to this repository because they can be reproduced from `A3BX3.py` and `dataset.csv`.

## Study overview

This work develops a physics-informed machine-learning workflow for predicting and interpreting the simulated photovoltaic performance of inverse or anti-perovskite solar cells with an A3BX3-type structure.

The dataset contains device records compiled mainly from published SCAPS-1D simulation studies. The input variables include absorber, electron transport layer, and hole transport layer descriptors, such as layer thickness, band gap, electron affinity, dielectric constant, carrier mobility, doping concentration, and defect density. In addition to these original descriptors, physically informed derived features are constructed to represent carrier-transport balance, interfacial energy-level alignment, defect distribution, thickness--defect coupling, and transport bottlenecks.

The code trains and compares four regression models for predicting:

- open-circuit voltage, `Voc`;
- short-circuit current density, `Jsc`;
- fill factor, `FF`;
- power conversion efficiency, `PCE`.

The compared models include random forest, XGBoost, multilayer perceptron, and deep multilayer perceptron. The script also performs repeated random-seed evaluation and structure-level leave-one-out validation.

## Dataset

The input dataset should be named:

```text
dataset.csv
```

The dataset should be placed in the same directory as `A3BX3.py`.

The expected target columns are:

```text
Voc
Jsc
FF
PCE
```

The dataset may also contain a structure identifier column named:

```text
Name
```

This column is used for structure-level leave-one-out validation. In this validation, all records belonging to one complete device structure are held out as the test set, while records from the remaining structures are used for training.

## Usage

Run the full analysis with:

```bash
python A3BX3.py
```

The script will automatically read `dataset.csv`, clean the data, construct physically informed features, train the machine-learning models, perform validation, and export the manuscript-related tables as CSV files.

## Structure-level leave-one-out validation

The structure-level leave-one-out validation is included to test extrapolation behavior at the device-stack level. In each run, one complete structure is removed from the training set and used as the test set. This validation is more stringent than a random train--test split because the model must predict a device structure that is absent from the training data.

The structure-level validation results should be interpreted cautiously. Negative R2 values may occur for some held-out structures, especially when the target values within the held-out group have a narrow range or when the structure differs strongly from the training structures.

## Notes on SCAPS-1D optimization

The optimized device-performance values discussed in the manuscript were obtained from SCAPS-1D simulations guided by machine-learning interpretation results. They were not obtained by directly maximizing an XGBoost surrogate model.

The SCAPS-1D software itself is not redistributed in this repository.

## Reproducibility

To reproduce the analysis:

1. Place `A3BX3.py` and `dataset.csv` in the same folder.
2. Install the required Python packages.
3. Run `python A3BX3.py`.
4. Check the generated CSV files in the output folder.

No precomputed result files are required.
